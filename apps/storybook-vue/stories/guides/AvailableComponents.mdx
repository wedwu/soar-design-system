# Available components

Everything on this page is generated: from this Storybook's atom pages, from Web Awesome {WA_VERSION}'s own component metadata on the CDN, and from Soar Awesome's component manifest. It updates itself when an atom page is added or Web Awesome is upgraded.

**Loading:** with the CDN there's nothing to import. Every `<wa-*>` element loads itself the first time it appears on the page, through Web Awesome's loader script, and Soar Awesome's bundle registers the `<ax-*>` components. The four `<link>`/`<script>` tags are in each release's `snippet.html`.

## Atoms ({atoms.length})

Web Awesome components, restyled by Soar Awesome. Each page shows the component in Vue, with examples for Angular, React and plain JavaScript.

## In Web Awesome, not yet documented here ({undocumented.length})

These are on the CDN with the rest of Web Awesome, so they **work today** and pick up Soar Awesome's colors, spacing and type automatically. They haven't been reviewed or documented as atoms in this Storybook yet.

- **Use with care.** Check the [Web Awesome docs](https://webawesome.com/docs/components) for usage, and check accessibility yourself.
- **To promote one,** add `<Name>.stories.ts`, `<Name>.data.json` (with its Web Awesome page under `design.webAwesomeDocs`) and `<Name>.mdx` under `stories/atoms/`. It then moves to the Atoms table above automatically.
