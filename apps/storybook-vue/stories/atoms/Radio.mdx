# Radio

Lets users pick exactly one option from a set. This is Web Awesome's `wa-radio-group` with `wa-radio` options, loaded from the CDN and used directly in Vue templates, exactly as on a CDN page.

There are no component-specific changes.

Radios always go inside `<wa-radio-group>`. The group owns the label, hint, value, validation and form participation, so the controls below configure the group.

<wa-tab-panel name="vue">

`<wa-radio-group>` is a custom element, not a Vue component, so `v-model` doesn't work on it. Set the starting value with `value`, and read the current one from the group on `change`:

```vue
<script setup>
import { ref } from 'vue';
const cycle = ref('monthly');
</script>

<template>
  <wa-radio-group label="Billing cycle" name="billing" :value="cycle" @change="cycle = $event.target.value">
    <wa-radio value="monthly">Monthly</wa-radio>
    <wa-radio value="annual">Annual</wa-radio>
  </wa-radio-group>
</template>
```

Bind on/off attributes such as `disabled` and `required` as `x || undefined`. If Vue renders the group before the CDN script has loaded, it writes attributes, and `disabled="false"` would still count as disabled.

</wa-tab-panel>
<wa-tab-panel name="angular">

Add `CUSTOM_ELEMENTS_SCHEMA` so Angular accepts the `wa-*` tags. Set the starting value with `value`, and read the current one on `(change)`.

```ts
import { CUSTOM_ELEMENTS_SCHEMA, Component, signal } from '@angular/core';

@Component({
  selector: 'app-billing-cycle',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <wa-radio-group label="Billing cycle" name="billing" [attr.value]="cycle()" (change)="cycle.set($any($event.target).value)">
      <wa-radio value="monthly">Monthly</wa-radio>
      <wa-radio value="annual">Annual</wa-radio>
    </wa-radio-group>
  `,
})
export class BillingCycleComponent {
  readonly cycle = signal('monthly');
}
```

Bind on/off attributes with `[attr.required]="x ? '' : null"`: `null` removes the attribute, so `false` never ends up as `required="false"`.

</wa-tab-panel>
<wa-tab-panel name="react">

React 19 supports custom elements directly; no wrapper is needed. Pass `value`, and read the current one in `onchange` (the native event, lowercase).

```jsx
import { useState } from 'react';

export function BillingCycle() {
  const [cycle, setCycle] = useState('monthly');

  return (
    <wa-radio-group label="Billing cycle" name="billing" value={cycle} onchange={(event) => setCycle(event.target.value)}>
      <wa-radio value="monthly">Monthly</wa-radio>
      <wa-radio value="annual">Annual</wa-radio>
    </wa-radio-group>
  );
}
```

React 19 handles on/off attributes correctly, even before the CDN script has loaded: `required={false}` leaves the attribute off. In TypeScript, declare the `wa-*` tags for JSX, as `samples/react-vite/src/custom-elements.d.ts` does for Soar Awesome's own components.

</wa-tab-panel>
<wa-tab-panel name="javascript">

On a page without a framework, load the CDN files and write the markup. Read the group's `value` on `change`.

```html
<link rel="stylesheet" href="https://cdn.soarawesome.internal/webawesome/3.14.0/styles/webawesome.css" />
<link rel="stylesheet" href="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.css" />
<script type="module" src="https://cdn.soarawesome.internal/webawesome/3.14.0/webawesome.loader.js"></script>
<script type="module" src="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.min.js"></script>

<wa-radio-group id="cycle" label="Billing cycle" name="billing" value="monthly">
  <wa-radio value="monthly">Monthly</wa-radio>
  <wa-radio value="annual">Annual</wa-radio>
</wa-radio-group>

<script type="module">
  const group = document.querySelector('#cycle');
  group.addEventListener('change', () => {
    console.log('cycle:', group.value);
  });
</script>
```

The four `<link>`/`<script>` tags, with integrity hashes, are in each Soar Awesome release's `snippet.html`; `cdn.soarawesome.internal` stands for your CDN host.
