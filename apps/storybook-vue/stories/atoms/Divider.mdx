# Divider

Separates content with a horizontal or vertical line. This is Web Awesome's `wa-divider`, loaded from the CDN and used directly in Vue templates as `<wa-divider>`, exactly as on a CDN page.

There are no component-specific changes. The line color is `--wa-color-surface-border`.

<Canvas of={DividerStories.Playground} />

<Controls />

## Vertical

Use `orientation="vertical"` between inline items, such as toolbar actions.

<Canvas of={DividerStories.Vertical} />

## With a label

Text inside the divider becomes its label. `label-placement` moves it to the start, center or end.

<wa-tab-panel name="vue">

`<wa-divider>` has no on/off attributes or events, so it works in Vue templates as written. Bind `orientation` if it changes.

```vue
<script setup>
defineProps({ orientation: { type: String, default: 'vertical' } });
</script>

<template>
  <div style="display: flex; align-items: center; gap: var(--wa-space-s); height: 1.5rem">
    Edit
    <wa-divider :orientation="orientation"></wa-divider>
    Share
  </div>
</template>
```

</wa-tab-panel>
<wa-tab-panel name="angular">

Add `CUSTOM_ELEMENTS_SCHEMA` so Angular accepts the `wa-*` tags. The divider has no events; bind `orientation` if it changes.

```ts
import { CUSTOM_ELEMENTS_SCHEMA, Component, input } from '@angular/core';

@Component({
  selector: 'app-toolbar-divider',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <div style="display: flex; align-items: center; gap: var(--wa-space-s); height: 1.5rem">
      Edit
      <wa-divider [attr.orientation]="orientation()"></wa-divider>
      Share
    </div>
  `,
})
export class ToolbarDividerComponent {
  readonly orientation = input('vertical');
}
```

</wa-tab-panel>
<wa-tab-panel name="react">

React 19 supports custom elements directly; no wrapper is needed. The divider has no events; pass `orientation` as a prop.

```jsx
export function ToolbarDivider({ orientation = 'vertical' }) {
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 'var(--wa-space-s)', height: '1.5rem' }}>
      Edit
      <wa-divider orientation={orientation}></wa-divider>
      Share
    </div>
  );
}
```

In TypeScript, declare the `wa-*` tags for JSX, as `samples/react-vite/src/custom-elements.d.ts` does for Soar Awesome's own components.

</wa-tab-panel>
<wa-tab-panel name="javascript">

On a page without a framework, load the CDN files and write the markup. No script is needed.

```html
<link rel="stylesheet" href="https://cdn.soarawesome.internal/webawesome/3.14.0/styles/webawesome.css" />
<link rel="stylesheet" href="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.css" />
<script type="module" src="https://cdn.soarawesome.internal/webawesome/3.14.0/webawesome.loader.js"></script>
<script type="module" src="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.min.js"></script>

<div style="display: flex; align-items: center; gap: var(--wa-space-s); height: 1.5rem">
  Edit
  <wa-divider orientation="vertical"></wa-divider>
  Share
</div>
```

The four `<link>`/`<script>` tags, with integrity hashes, are in each Soar Awesome release's `snippet.html`; `cdn.soarawesome.internal` stands for your CDN host.
