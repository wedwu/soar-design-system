# Input

A single-line text field, for names, emails, passwords, numbers and search. This is Web Awesome's `wa-input`, loaded from the CDN and used directly in Vue templates as `<wa-input>`, exactly as on a CDN page.

Soar makes one adjustment in `parts.css`: labels are one step smaller than the value text (`--wa-font-size-s`), through `wa-input::part(form-control-label)`. The component itself is untouched.

For Soar's validation behavior (errors shown on blur, a character counter, taking part in an outer form), use the **ax-field** molecule.

Typing appears in the **Actions** panel.

<wa-tab-panel name="vue">

`<wa-input>` is a custom element, not a Vue component, so `v-model` doesn't work on it. Bind `value`, and read the current value on `input`:

```vue
<script setup>
import { ref } from 'vue';
const name = ref('');
</script>

<template>
  <wa-input label="Project name" :value="name" @input="name = $event.target.value"></wa-input>
</template>
```

Bind on/off attributes such as `required`, `disabled` and `readonly` as `x || undefined`. If Vue renders the input before the CDN script has loaded, it writes attributes, and `disabled="false"` would still count as disabled.

</wa-tab-panel>
<wa-tab-panel name="angular">

Add `CUSTOM_ELEMENTS_SCHEMA` so Angular accepts the `wa-*` tags. Read the current value on `(input)`.

```ts
import { CUSTOM_ELEMENTS_SCHEMA, Component, signal } from '@angular/core';

@Component({
  selector: 'app-project-name',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <wa-input label="Project name" [attr.required]="nameRequired() ? '' : null" (input)="name.set($any($event.target).value)"></wa-input>
    <p>Name: {{ name() }}</p>
  `,
})
export class ProjectNameComponent {
  readonly name = signal('');
  readonly nameRequired = signal(true);
}
```

Bind on/off attributes with `[attr.required]="x ? '' : null"`: `null` removes the attribute, so `false` never ends up as `required="false"`.

</wa-tab-panel>
<wa-tab-panel name="react">

React 19 supports custom elements directly; no wrapper is needed. Pass `value`, and read the current one in `oninput` (the native event, lowercase).

```jsx
import { useState } from 'react';

export function ProjectName() {
  const [name, setName] = useState('');

  return (
    <>
      <wa-input label="Project name" required value={name} oninput={(event) => setName(event.target.value)}></wa-input>
      <p>Name: {name}</p>
    </>
  );
}
```

React 19 handles on/off attributes correctly, even before the CDN script has loaded: `required={false}` leaves the attribute off. In TypeScript, declare the `wa-*` tags for JSX, as `samples/react-vite/src/custom-elements.d.ts` does for Soar Awesome's own components.

</wa-tab-panel>
<wa-tab-panel name="javascript">

On a page without a framework, load the CDN files and write the markup. Read `value` on `input`.

```html
<link rel="stylesheet" href="https://cdn.soarawesome.internal/webawesome/3.14.0/styles/webawesome.css" />
<link rel="stylesheet" href="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.css" />
<script type="module" src="https://cdn.soarawesome.internal/webawesome/3.14.0/webawesome.loader.js"></script>
<script type="module" src="https://cdn.soarawesome.internal/soarawesome/0.1.0/soarawesome.min.js"></script>

<wa-input id="project-name" label="Project name" required></wa-input>

<script type="module">
  const input = document.querySelector('#project-name');
  input.addEventListener('input', () => {
    console.log('name:', input.value);
  });
</script>
```

The four `<link>`/`<script>` tags, with integrity hashes, are in each Soar Awesome release's `snippet.html`; `cdn.soarawesome.internal` stands for your CDN host.
